This program writes a single one-line excuse from a robot vacuum for missing a spot. The vacuum reports, in its own deadpan voice, that the household cat sat on the spot at 09:00 sharp, so under squatters' rights it vacuumed around her and let her keep the dust — the one thing it was sent to remove, conceded to the cat.

## Run it

```sh
python3 main.py
```
